# Maroli Comunicação Visual — protótipo de site

Site demonstrativo responsivo em HTML, CSS e JavaScript, inspirado na identidade visual laranja, preto e branco da Maroli.

## Funcionalidades deste protótipo
- Layout responsivo para desktop, tablet e celular.
- Menu mobile.
- Seções institucionais, serviços, portfólio, sobre e orçamento.
- Formulário de orçamento que prepara uma mensagem para o WhatsApp.
- Botões para Instagram e WhatsApp.

## Limitação importante
Este projeto é somente um **protótipo front-end**.
